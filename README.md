# TallerOs
Sistema inteligente de gestión de talleres de automóviles y motocicletas.

## Ejecución

```bash
dotnet run --project src/TallerOs.Cli/TallerOs.Cli.csproj
```

La aplicación ejecuta una función básica de bienvenida. El archivo `.gitignore`
evita subir archivos generados por .NET y archivos locales de Visual Studio.
